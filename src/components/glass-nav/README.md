# GlassNav — شريط التنقل الزجاجي

كبسولة عائمة شفافة أسفل الشاشة، بثلاث تبويبات بترتيب RTL (المكتبة / المجموعات / الحساب)، وأيقونة نشطة ممتلئة بتدرّج ناعم.
مكوّن عميل React/TypeScript جاهز للاستخدام في أي صفحة داخل المشروع.

## التركيب الحالي

الشريط مُدمج في `src/components/Header.tsx` ويظهر في كل الصفحات:

```tsx
import { GlassNav } from './glass-nav/GlassNav';

<GlassNav onSelect={(key) => key === 'account' && openAccount()} />;
```

- التبويبان الأوليان روابط تنقّل حقيقية (`next/link`): `/library`، `/collections`.
- تبويب `account` زر بلا `href`؛ الحدث `onSelect` يفتح الحساب كما يفتحه Avatar تمامًا (منبثق على الحاسوب، صفحة `/account` كاملة على الهاتف).
- (دفعة التنقل 1) أُزيل تبويبا «اضافة» و«المحفوظات» من الشريط: المحفوظات ضمن `/account`، وإتاحة الإرسال على الهاتف عبر صفحة الحساب (حسم حمدان 2026-10-22) — مفتاحاهما يبقيان في النوع `GlassTabKey` وكائن `Icons` نظافةً للواجهة البرمجية.
- التبويب النشط يُستنتج تلقائيًا من `usePathname()` عبر حقل `isCurrent` في كل تبويب.

## الخصائص (Props)

| الخاصية     | النوع                | الافتراضي        | الوصف                                                     |
| ----------- | -------------------- | ---------------- | --------------------------------------------------------- |
| `tabs`      | `GlassTab[]`         | `DEFAULT_TABS`   | التبويبات: `key`, `label`, `href?`, `aria?`, `isCurrent?` |
| `activeKey` | `GlassTabKey`        | —                | يفرض التبويب النشط ويتجاوز استنتاج المسار                 |
| `onSelect`  | `(key, tab) => void` | —                | يُنادى عند كل تنشيط قبل الانتقال                          |
| `className` | `string`             | —                | أصناف إضافية تُدمج بعد `glass-nav`                        |
| `style`     | `CSSProperties`      | —                | أنماط مباشرة (تتجاوَز قيم CSS)                            |
| `ariaLabel` | `string`             | `التنقل الرئيسي` | اسم قارئ الشاشة للشريط                                    |

## أيقونات مخصّصة

كل أيقونة طبقتان داخل نفس `<svg>`:

- `.s-o` — المخطط (يظهر في الحالة غير النشطة، `stroke="currentColor"`).
- `.s-f` — الممتلئ بتدرّج (`gv` رأسي + `gr` تعتيم حواف)، يظهر بتلاشٍ 240ms عند التنشيط.

لإضافة تبويب بأيقونة جديدة، أضف مفتاحًا إلى كائن `Icons` في `GlassNav.tsx` وأضف التبويب إلى `tabs`.

## المقاسات والثيم

كل المقاسات مشتقّة من متغيّر واحد في `glass-nav.css`:

```css
--gnav-h: clamp(74px, 8.5vw, 96px); /* ارتفاع الكبسولة */
--gnav-w: min(520px, calc(100vw - 24px)); /* أقصى عرض */
--gnav-icon: calc(var(--gnav-h) * 0.24); /* نسبة التصميم الأصلية */
--gnav-font-family: var(--f-body); /* خط المشروع */
```

- **الوضع الداكن:** يتكيّف تلقائيًا عبر `:root[data-theme='dark']` (زجاج داكن + تدرّج أيقونة فاتح).
- **تقليل الحركة:** يتبع `prefers-reduced-motion` و`:root[data-motion='reduce']`.
- **عدم تغطية المحتوى:** يُضاف حشو أسفل الصفحة تلقائيًا عبر `body:has(> .glass-nav)`.
- **إخفاء الشريط على الحاسوب** (لو أردت الاقتصار على الهاتف):

```css
@media (min-width: 1024px) {
  .glass-nav {
    display: none;
  }
  body:has(> .glass-nav) {
    padding-bottom: 0;
  }
}
```

## الوصولية

- `aria-current="page"` على الرابط النشط، و`aria-label` لكل تبويب.
- أسهم لوحة المفاتيح (`ArrowLeft` / `ArrowRight` / `Home` / `End`) تتبع اتجاه RTL تلقائيًا.
- `focus-visible` واضح بلون الـAccent، والأيقونات `aria-hidden`.
- معرّفات التدرّجات مبنية على `useId()` لتتطابق بين العرض على الخادم والعميل.

## التحقق

- `corepack pnpm typecheck` — نظيف.
- `corepack pnpm test` — 93 ناجحًا (بلا إخفاقات جديدة عن خط الأساس).
- `corepack pnpm build` — بناء إنتاج ناجح.
- تحقّق متصفح فعلي (Chromium): ترتيب RTL صحيح، تنقّل إلى `/collections`، صفحة الحساب على الهاتف ومنبثق على الحاسوب، بلا أخطاء JS.
