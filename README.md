# YemReact — الموقف يمني. والردّ جاهز.

إعادة بناء كاملة لتجربة YemReact: مكتبة عربية RTL، مظهر ورقي/كهرماني مع وضع ليلي، معاينة فيديو وتنزيل ومشاركة، محفوظات، حسابات فعلية، واستوديو إدارة بصلاحيات.

**نسخة Full-stack تجريبية قابلة للتشغيل، وليست إعلانًا عن اعتماد أمني أو جاهزية Enterprise مطلقة.** المقاطع الحالية نماذج صامتة متحركة من صور مولّدة، وموسومة بذلك داخل الواجهة.

## التشغيل

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

ثم افتح `http://localhost:3000`. الخادم مربوط على `0.0.0.0` للمعاينات الخارجية.

```bash
pnpm build
pnpm start
```

المعاينة المسلّمة تعمل ببناء الإنتاج على المنفذ 3000 لتقليل استهلاك الذاكرة.

## حساب المالك

التسجيل من المتصفح ينشئ **عضوًا** فقط. لا توجد كلمة مرور مدير افتراضية.

```bash
export ADMIN_EMAIL='owner@example.com'
read -s -p 'Owner password (12+ characters): ' ADMIN_PASSWORD
export ADMIN_PASSWORD
pnpm admin:create
unset ADMIN_PASSWORD
```

بعدها سجّل الدخول من `/login`. دليل الاستخدام في [docs/ADMIN-GUIDE.md](docs/ADMIN-GUIDE.md).

## ما يعمل

- بحث حي يطبّع العربية، تصفية بالفئة والمدة، ترتيب وعرض المزيد.
- معاينة داخل نافذة مع تشغيل حقيقي، تنقل بالأسهم/السحب، تنزيل MP4/WebM ومشاركة الرابط.
- محفوظات محلية للزائر ومجموعة منفصلة في قاعدة البيانات للحساب.
- تسجيل/دخول/خروج، جلسات HttpOnly وصلاحيات عضو/مدير على الخادم.
- إضافة/تعديل/حذف، رفع فيديو وغلاف، قائمة وسائط ومستخدمين، أحداث محلية وسجل عمليات وتصدير.
- مظهر تلقائي/نهاري/ليلي، ثلاثة ألوان مختارة وتخفيف الحركة.
- PWA للصفحات العامة المخزنة مع صفحة Offline؛ لا تُخزّن الحسابات أو الفيديوهات تلقائيًا.
- Metadata، OG، JSON-LD، sitemap، robots، صفحات 404 وحالات خطأ/تحميل.

## قبل النشر العام

اضبط `NEXT_PUBLIC_SITE_URL` إلى نطاق HTTPS فعلي و`DATA_DIR` إلى قرص دائم. أضف نسخًا احتياطية، حدود رفع ومعدل طلبات على مستوى البنية التحتية، تحقق البريد واستعادة الحساب، وفحصًا/تحويلًا للوسائط. استبدل النماذج بمقاطع مرخّصة وأضف ترجمة/نصوصًا لأي صوت.

لا يوجد OAuth أو SMTP أو دفع أو تعليقات أو مدونة أو متابعون. عدم إضافتها قرار نطاق، وليس أزرارًا وهمية أو تكاملات غير مكتملة مخفية.
