# Demo media provenance

The contact sheet and six portrait WebP files were generated for this prototype. They depict fictional adult characters, not identified people or authentic film/TV footage. The six MP4s animate these stills with a slow zoom and have no audio. UI copy discloses this in gallery, hero, player, detail and policy pages.

Durations for demo-1 to demo-6: 2, 3, 4, 3, 5 and 2 seconds. They are H.264 / yuv420p MP4 with faststart metadata. No remote stock-photo dependency or streaming service is required.

Before public launch, obtain and document rights for every replacement clip and add captions/transcripts if it contains speech. Do not remove demo labels from these files to present them as original footage.
