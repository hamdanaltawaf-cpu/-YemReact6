## درجة المطابقة والاختلافات
البنية المرئية الأساسية من ملفات المرجع نفسها، لا إعادة رسم مشابهة: عرض الحساب الأقصى 800px والإعدادات 640px، بطاقات التفضيلات ومعايناتها، ألوان الكهرماني والأخضر والوضع الداكن، زخارف الفراغ، المحفوظات وتبويباتها. أُخذت لقطات محلية عند 390 و1440 في الوضعين مع جلسات معزولة للزائر والعضو والمشرف. روجعت بصريًا عينات الحساب والإعدادات والهاتف الداكن الأخضر؛ ليست هناك نتيجة pixel-diff أو نسبة تطابق رقمية.

اختلافات مقصودة:
- لا خدمة حالية لمساهمات حقيقية؛ لذلك لم تُنسخ حالات وسجلات المرجع التجريبية كحقائق. إضافة خدمة فعلية تحتاج موافقة مستقلة.
- لم تُنسخ حسابات المرجع أو بياناتها أو خلفيته التجريبية. بقي /account/submissions كما هو.
- تكامل Google الحقيقي، الهوية العامة، التذييل والشريط السفلي القائمان محفوظة؛ لا إدخال لمسار /submit أو واجهة API جديدة أو دمج لمحفوظات الزائر بالحساب.
- لقطات بيئة التطوير قد تستخدم خطوط fallback نتيجة تعذر Google Fonts وتظهر مؤشر Next. لا تثبت مطابقة الخطوط النهائية.
- الشريط السفلي ثابت وقد يغطي محتوى في اللقطة الكاملة أثناء التمرير؛ لم يُعد تصميمه ولم يُدعَ حل كل حالات التراكب.
