# دليل الاستوديو

## دخول المالك

`/admin` يعرض مخزون المكتبة للعامة للمعاينة فقط. الأرقام الخاصة والمستخدمون وسجل العمليات والتعديل تحتاج حسابًا بدور `admin`.

لا توجد كلمة مرور افتراضية أو حساب مدير عام. أنشئ المالك من طرفية الخادم:

```bash
export ADMIN_EMAIL='owner@example.com'
read -s -p 'Owner password (12+ characters): ' ADMIN_PASSWORD
export ADMIN_PASSWORD
pnpm admin:create
unset ADMIN_PASSWORD
```

ثم افتح `/login` وسجّل بالبريد وكلمة المرور اللذين اخترتهما. إنشاء حساب من المتصفح يمنح دور عضو فقط؛ أول حساب لا يصبح مديرًا تلقائيًا.

## نشر قصاصة

1. افتح الاستوديو واضغط **رياكشن جديد**.
2. **الموقف:** الاقتباس، وصف الموقف، الفئة، الكلمات المفتاحية.
3. **الوسائط:** ارفع فيديو MP4/WebM بين 2 و8 ثوانٍ وبحجم لا يتجاوز 15MB. أضف صورة غلاف PNG/JPG/WebP، أو اختر نموذجًا تجريبيًا جاهزًا.
4. **المراجعة:** راجع الاقتباس والفئة والمدة. أكد حقك في مشاركة الفيديو المرفوع ثم انشر.
5. يظهر الرياكشن مباشرة في المكتبة. يبقى وسم «نموذج مولّد» ملازمًا للملفات التجريبية.

## التعديل والحذف

من **الرياكشنات** ابحث بالكود/الاقتباس ثم استخدم أزرار المعاينة أو التعديل أو الحذف. الحذف يحتاج تأكيدًا، ويزيل محفوظات الحسابات المرتبطة. لا يحذف الفيديو من القرص تلقائيًا لأن عدة قصاصات قد تشترك فيه. نُظّف الملفات غير المستخدمة بعد مراجعة إدارية.

## الوسائط والمستخدمون

- **الوسائط:** قائمة الملفات المرتبطة بالمكتبة بدون تكرار الفيديو نفسه، مع معاينة.
- **المستخدمون:** قراءة آخر 100 حساب، بدون كلمات مرور. ترقية/إعادة تعيين كلمة مرور المالك من CLI فقط.
- **سجل العمليات:** آخر 40 عملية إنشاء حساب/تعديل/حذف.
- **نظرة عامة:** توزيع الفئات وأحداث آخر سبعة أيام. هذه عدادات تشغيل/تنزيل/مشاركة وليست عدد أشخاص فريدين.
- **تصدير التقرير:** JSON للمكتبة والأحداث والسجل، بدون أسماء وبريد المستخدمين.

## حدود التشغيل

لا توجد خدمة رسائل أو تسجيل Google، ولا تحقق بريد أو استعادة كلمة مرور ذاتية. الحقوق مسؤولية الرافع، ولا توجد مراجعة آلية لمحتوى الفيديو أو فحص أمني متقدم للوسائط. صور النسخة الحالية مولّدة، وليست صور شخصيات موثقة أو مقاطع أصلية.
