# دليل الاستوديو

## دخول المالك

`/admin` متاح لحسابات `admin` فقط. رابط الاستوديو يظهر للمالك في صفحة حسابه `/login` وتذييل الصفحات التي تعرضه؛ لا تختلط الإدارة بالتنقل الأساسي أو ورقة الحساب، ولا يظهر الرابط للزائر/العضو. يتحقق الخادم من الجلسة والدور قبل عرض الصفحة: يحوّل الزائر إلى `/login`، ويعيد صفحة غير موجودة للحساب غير الإداري. تبقى واجهات API محمية أيضًا؛ إخفاء الرابط وحده ليس آلية الصلاحيات.

الدخول اجتماعي فقط عبر Google أو Apple أو Microsoft، بعد إعداد المزود على الخادم. انظر [SOCIAL-AUTH.md](SOCIAL-AUTH.md) لروابط العودة وإعدادات OAuth وترحيل الحسابات السابقة.

سجّل اجتماعيًا أولًا ثم رقِّ الحساب من الخادم:

```bash
ADMIN_USER_ID='<existing-social-user-id>' pnpm admin:create
```

ادخل بالخدمة نفسها مجددًا بعد تنفيذ الأمر. الحساب الجديد عضو فقط، ولا يصبح أول مستخدم مديرًا تلقائيًا. افتح المعاينة في تبويب مستقل لإكمال الدخول.

## نشر قصاصة

1. افتح الاستوديو واضغط **رياكشن جديد**.
2. **البيانات:** العنوان/الوصف الأساسي، وصف ثانوي اختياري، اسم شخصية اختياري، والكلمات المفتاحية.
3. **الوسائط:** ارفع صورة ثابتة JPG/PNG/WebP أو فيديو MP4/WebM من ثانيتين إلى 60 ثانية، حتى 15MB. يتحقق الخادم من المحتوى الفعلي للملف. يُستخرج غلاف الفيديو تلقائيًا ويمكن استبداله؛ الصورة المنشورة لا تحتاج غلافًا منفصلًا. يمكنك أيضًا اختيار نموذج تجريبي جاهز.
4. **المراجعة:** راجع الوصف والمعاينة: الصورة تُعرض كصورة، والفيديو بمشغّل حقيقي. أكد حقك في مشاركة الملف المرفوع ثم انشر.
5. يظهر الرياكشن مباشرة في المكتبة. يبقى وسم «نموذج مولّد» ملازمًا للملفات التجريبية.

## التعديل والحذف

من **الرياكشنات** ابحث بالكود/الوصف ثم استخدم أزرار المعاينة أو التعديل أو الحذف. الحذف يحتاج تأكيدًا، ويزيل محفوظات الحسابات المرتبطة. لا يحذف الملف من القرص تلقائيًا لأن عدة قصاصات قد تشترك فيه. نُظّف الملفات غير المستخدمة بعد مراجعة إدارية.

## تنسيق المجموعات والبلاغات

- تبويب **المجموعات** داخل `/admin` وحده يسمح بإنشاء مجموعة موضوعية أو شخصية أو جغرافية، تغيير عنوانها ووصفها والغلاف (من أحد أعضائها)، تعيين عدة رياكشنات لها أو أرشفتها. يمكن إضافة الرياكشن إلى أكثر من مجموعة.
- تظهر المجموعات العامة النشطة ذات العناصر الفعلية في `/collections` وصفحات تفاصيلها. تغيير المجموعة لا يغيّر تصنيف الوسيط القديم أو المحفوظات.
- تبويب **البلاغات** يعرض أحدث 100 بلاغ مرسل من قائمة النقاط الثلاث. راجع المصدر وحقوقه يدويًا؛ إرسال البلاغ لا يحذف الوسيط تلقائيًا.

## الوسائط والمستخدمون

- **الوسائط:** قائمة الملفات المرتبطة بالمكتبة بدون تكرار الملف نفسه، مع معاينة.
- **المستخدمون:** قراءة آخر 100 حساب، بدون كلمات مرور. ترقية المالك وربط الحسابات السابقة من CLI الموثوق فقط.
- **سجل العمليات:** آخر 40 عملية إنشاء حساب/تعديل/حذف.
- **نظرة عامة:** توزيع الفئات وأحداث آخر سبعة أيام. هذه عدادات تشغيل/تنزيل/مشاركة وليست عدد أشخاص فريدين.
- **تصدير التقرير:** JSON للمكتبة والأحداث والسجل، بدون أسماء وبريد المستخدمين.

## حدود التشغيل

تفعيل Google وApple وMicrosoft يحتاج مفاتيح المزودين. لا توجد خدمة رسائل أو ربط ذاتي لمزود إضافي. الحقوق مسؤولية الرافع، ولا توجد مراجعة آلية لمحتوى الفيديو أو فحص أمني متقدم للوسائط. صور النسخة الحالية مولّدة، وليست صور شخصيات موثقة أو مقاطع أصلية.
