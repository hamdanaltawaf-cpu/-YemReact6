# دليل الاستوديو

## دخول المالك

`/admin` متاح لحسابات `admin` فقط. رابط الاستوديو مخفي عن الزوار والأعضاء في قوائم الكمبيوتر والهاتف والتذييل. يتحقق الخادم من الجلسة والدور قبل عرض الصفحة: يحوّل الزائر إلى `/login`، ويعيد صفحة غير موجودة للحساب غير الإداري. تبقى واجهات API محمية أيضًا؛ إخفاء الرابط وحده ليس آلية الصلاحيات.

الدخول اجتماعي فقط عبر Google أو Apple أو Microsoft، بعد إعداد المزود على الخادم. انظر [SOCIAL-AUTH.md](SOCIAL-AUTH.md) لروابط العودة وإعدادات OAuth وترحيل الحسابات السابقة.

سجّل اجتماعيًا أولًا ثم رقِّ الحساب من الخادم:

```bash
ADMIN_USER_ID='<existing-social-user-id>' pnpm admin:create
```

ادخل بالخدمة نفسها مجددًا بعد تنفيذ الأمر. الحساب الجديد عضو فقط، ولا يصبح أول مستخدم مديرًا تلقائيًا. افتح المعاينة في تبويب مستقل لإكمال الدخول.

## نشر قصاصة

1. افتح الاستوديو واضغط **رياكشن جديد**.
2. **الموقف:** الاقتباس، وصف الموقف، الفئة، الكلمات المفتاحية.
3. **الوسائط:** ارفع فيديو MP4/WebM من ثانيتين إلى 60 ثانية وبحجم لا يتجاوز 15MB. أضف صورة غلاف PNG/JPG/WebP، أو اختر نموذجًا تجريبيًا جاهزًا.
4. **المراجعة:** راجع الاقتباس والفئة والمدة. أكد حقك في مشاركة الفيديو المرفوع ثم انشر.
5. يظهر الرياكشن مباشرة في المكتبة. يبقى وسم «نموذج مولّد» ملازمًا للملفات التجريبية.

## التعديل والحذف

من **الرياكشنات** ابحث بالكود/الاقتباس ثم استخدم أزرار المعاينة أو التعديل أو الحذف. الحذف يحتاج تأكيدًا، ويزيل محفوظات الحسابات المرتبطة. لا يحذف الفيديو من القرص تلقائيًا لأن عدة قصاصات قد تشترك فيه. نُظّف الملفات غير المستخدمة بعد مراجعة إدارية.

## الوسائط والمستخدمون

- **الوسائط:** قائمة الملفات المرتبطة بالمكتبة بدون تكرار الفيديو نفسه، مع معاينة.
- **المستخدمون:** قراءة آخر 100 حساب، بدون كلمات مرور. ترقية المالك وربط الحسابات السابقة من CLI الموثوق فقط.
- **سجل العمليات:** آخر 40 عملية إنشاء حساب/تعديل/حذف.
- **نظرة عامة:** توزيع الفئات وأحداث آخر سبعة أيام. هذه عدادات تشغيل/تنزيل/مشاركة وليست عدد أشخاص فريدين.
- **تصدير التقرير:** JSON للمكتبة والأحداث والسجل، بدون أسماء وبريد المستخدمين.

## حدود التشغيل

تفعيل Google وApple وMicrosoft يحتاج مفاتيح المزودين. لا توجد خدمة رسائل أو ربط ذاتي لمزود إضافي. الحقوق مسؤولية الرافع، ولا توجد مراجعة آلية لمحتوى الفيديو أو فحص أمني متقدم للوسائط. صور النسخة الحالية مولّدة، وليست صور شخصيات موثقة أو مقاطع أصلية.
