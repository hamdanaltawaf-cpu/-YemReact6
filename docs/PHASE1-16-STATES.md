# Phase 1 — البند 16: التحميل والأخطاء وعدم الاتصال

تاريخ التنفيذ: 2026-11-07. التفويض: تنفيذ البند 16 فقط بعد تصحيح رقم الاعتماد من صاحب المشروع. الحالة عند إعداد التقرير: تحقق محلي ناجح؛ أذن صاحب المشروع لاحقًا بالدمج والنشر التلقائي عبر PR بعد الفحوص. نتيجة النشر الفعلية تسجّل في PR وتقرير التسليم.

## ما تم

- مكوّن `StatePanel` مشترك لعرض الفراغ، الخطأ، الصفحة غير الموجودة، عدم الاتصال، التحميل، ومواصفة منع الصلاحية. الحالات مميزة بنص وأيقونة، لا باللون وحده.
- خطأ الصفحة: إجراء «إعادة المحاولة» يستدعي `reset` الحقيقي. أزيل الادعاء غير المتحقق «بياناتك المحفوظة لم تُحذف». لا عرض لتفاصيل الخطأ الداخلية.
- الصفحة غير الموجودة وعدم الاتصال: رابط موجود إلى المكتبة، بلا إعادة محاولة صورية أو وعد بوجود كل الوسائط في التخزين المؤقت.
- المكتبة: الحفاظ على مسح البحث ومعاملات التصفية، مع المكوّن المشترك لحالة الفراغ؛ لا تحويل الفراغ إلى خطأ شبكة.
- التحميل: 12 هيكل بطاقة، أعمدة 2/3/4/5/6 بحسب المقاس، وسائط بنسبة 4:5 وسطر عنوان، دون وميض مستمر أو نسبة تقدم مختلقة. `aria-busy` للحالة و`aria-hidden` للزخرفة.
- إرسالاتي: أزيل مؤقت 260ms الذي كان يؤخر نهاية التحميل؛ الحالة مشتقة من `contribution.ready` و`app.authReady` فقط. لم تتغير شروط السماح أو السجلات أو أزرار النموذج.
- دخول الحالة: Fade مع إزاحة 5px ومقياس 0.99 خلال 180ms. خروج الحالة داخل الحدود المثبتة: Fade ومقياس 0.985 خلال 160ms عبر AnimatePresence. التحويم على الإجراء يرفع الزر 2px خلال 160ms للأجهزة المناسبة فقط.
- إيقاف الحركة عند تفضيل النظام أو إعداد التطبيق، مع تركيز مرئي وأهداف إجراء لا تقل عن 44px والتفاف النص الطويل. إعادة استخدام الألوان الحالية؛ لا ألوان أو تبعيات إنتاج جديدة.

## مكتبة مواصفات الحالات

| الحالة | الدلالة | الإجراء | الوصول |
|---|---|---|---|
| empty | استعلام أو قائمة لا تحتوي نتائج، وليس فشل طلب | مسح البحث/العودة مع المحافظة على المعاملات الأخرى | status / polite |
| error | فشل تحميل حقيقي التقطه Error Boundary | reset لإعادة محاولة التحميل | alert / assertive |
| not-found | الصفحة أو العنصر غير موجود | العودة إلى المكتبة؛ حالة HTTP يديرها Next | status / polite |
| offline | إيضاح حدود الاستخدام دون اتصال | العودة إلى المكتبة؛ دون وعد بوجود نسخة مخزنة | status / polite |
| loading | انتظار حقيقي لتجهيز المحتوى | لا إجراء وهمي ولا توقيت مصطنع | status / polite / busy |
| permission | منع العرض، لا خطأ شبكة ولا قائمة فارغة | يمرر المستدعي فقط إجراءً حقيقيًا ومصرحًا إن وجد | status / polite |

العقد: `kind`, `title`, `description?`, `action?`, `children?`, `visible?`, `heading?`. أبقِ `StatePanel` مثبتًا وغيّر `visible` للاستفادة من حركة الخروج؛ المستوى h1 لصفحة كاملة وh2 لحالة داخل قسم. لا تستخدمه لتأكيد نجاح عملية لم تُؤكد.

## التحقق

- الاختبارات الآلية: 175/175 ناجحة، بلا اختبارات متخطاة. TypeScript والتنسيق و`git diff --check` ناجحة.
- متصفح Chromium محلي: 16/16 تحققًا ناجحًا؛ عدم التجاوز الأفقي لحالة عدم الاتصال عند 320/375/768/1024/1920px في الفاتح والداكن، والنص الطويل والكلمات غير المنفصلة عند 320px؛ تفضيلا تخفيف الحركة؛ رابط مسح البحث وزوال حالة الفراغ بعد الضغط؛ تمييز صفحة 404.
- لقطات محلية: `offline-mobile.png`, `empty-mobile.png`, `not-found-mobile.png` ضمن حزمة الأدلة المصاحبة. اختبارات الحالة المعزولة تغطي التحميل والخطأ ومنع الصلاحية؛ ليست لقطات لتلك الحالات.
- بيانات الاختبار محلية ومعزولة خارج المستودع. أدوات المتصفح وFFmpeg خارج تبعيات التطبيق. لا OAuth أو إرسال نموذج أو كتابة بيانات حية.

## التعارضات والحدود وما لم يكتمل

- لا تعارض يتطلب تعديل المصادقة أو API أو قاعدة البيانات أو Service Worker أو المكونات العامة الأخرى. لا إعادة تصميم للشعار أو التنقل أو لوحة الألوان، ولا إضافة حالات قبول ورفض الصورة المرجعية إلى تدفق المساهمات.
- **الخروج عند التنقل الكامل:** Next قد يزيل الصفحة أو loading boundary فورًا؛ لا ضمان لحركة خروج في تلك الحالة. الخروج منفذ للحالة المحلية عند تغيير `visible`. تعميمه على التنقل يتطلب اعتمادًا منفصلًا لتجنب تغيير سلوك الصفحات العامة.
- **منع الصلاحية:** مواصفة ومكوّن واختبار فقط؛ لم أغير صفحات أو إحالات الحماية لإظهار رسالة جديدة.
- **التحميل والخطأ:** لم أفتعل عطلًا إنتاجيًا أو أضيف تأخيرًا لإظهار تحميل؛ تشغيل reset تحت خطأ متصفح فعلي وتدقيق قارئ شاشة/axe كامل لم يُنفذا. لا ادعاء بمطابقة WCAG كاملة.
- فحص المقاسات والثيمين على المتصفح يخص حالة عدم الاتصال؛ لا يُعد تغطية لكل حالة وكل مقاس. لقطات الفراغ و404 محلية وليست إثباتًا لنشر حي.
- لم أجر بناء إنتاج أو قياسات أداء أو تحققًا حيًا؛ معاينة Next dev لا تثبت نجاح بناء الإنتاج أو تحميل الخطوط هناك. لم أغير إعداد الخطوط أو أتحايل عليه.
- #418 وPurple/Teal واكتمال المزامنة خارج هذا البند؛ لا ادعاء بحلها. الدمج والنشر اللاحقان مأذونان بطلب صريح؛ لا دفع مباشر إلى main أو Manual Deploy.
